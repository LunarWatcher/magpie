## Changed

* HTTP/1.1: The number of headers is now limited to 50 (configurable via AppConfig's `limits`)
* HTTP/1.1: The length of a header is now limited to 16KiB (configurable via AppConfig's `limits`)
* HTTP/1.1: The max body length is now limited to 16MiB (configurable via AppConfig's `limits`)
