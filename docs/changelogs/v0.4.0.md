## Added

* Added methods to `App` for getting the address for the server (i.e. IP address), as well as a connection string that can be used when magpie is used locally, or to troubleshoot connections.
* Added function to the protocol adapters that returns the protocol name so the connection string can be correct on non-HTTP protocols

## Changed

* HTTP/1.1: The number of headers is now limited to 50 (configurable via AppConfig's `limits`)
* HTTP/1.1: The length of a header is now limited to 16KiB (configurable via AppConfig's `limits`)
* HTTP/1.1: The max body length is now limited to 16MiB (configurable via AppConfig's `limits`)
